# A country's continent is its M49 region: Africa (002), Asia (142), Europe (150) or Oceania (009);
# in the Americas (019) it is South America (005) or North America (003), which M49 defines as
# Northern America, Central America and the Caribbean (https://unstats.un.org/unsd/methodology/m49/,
# SHA-256 4d5cabcb10ad9ef184553b5e64c0a34ba8deeb20dab2e02cd0be3599b93bb01d). A transcontinental
# country therefore has one continent: RU is Europe; TR, CY, GE, AM, AZ and KZ are Asia; EG is
# Africa. AQ is Antarctica: M49 places it in no region, and CLDR only in its own Outlying Oceania
# group (QO), which is not an M49 region. TW, which M49 does not list, is in CLDR's Eastern Asia
# (030), so Asia.
