SchemaOutputBenchmark for 3.0.2: a child stream's configuration copied from a parent without modules.

This is not a full dashboard run: only SchemaOutputBenchmark ran, before and after the change, in one
sitting, on one machine where other work also ran, with the publication protocol of METHODOLOGY.md.
Three runs whose error bars showed that work were repeated: one before the change, whose
largeSchemaBatch gave 193.344 ± 11.928 ops/s, and two after it, which gave 236.610 ± 21.323 and
244.605 ± 11.058 ops/s with code that differed from ce1b8774 only in the wording of one comment. Each
operation generates or writes 250 records of twelve Field references, seeded with 7.

Environment: Temurin 21.0.13+9, Darwin 27.2.0 arm64, Apple M5 Pro, JMH 1.37
Command: ./gradlew :benchmarks:jmh -PjmhArgs="SchemaOutputBenchmark -foe true -wi 3 -i 5 -f 3 -t 1 -prof gc"
