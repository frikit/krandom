SchemaOutputBenchmark for 3.0.3: each locale's street secondary units read once.

This is not a full dashboard run: only SchemaOutputBenchmark ran, before and after the change, in one
sitting, on one machine, with the publication protocol of METHODOLOGY.md, in the order before, after,
after, before. Each run had the machine to itself through a lock that kept every other heavy job off it.
Each operation generates or writes 250 records of twelve Field references, seeded with 7.

Environment: Temurin 21.0.13+9, Darwin 27.2.0 arm64, Apple M5 Pro, JMH 1.37
Command: ./gradlew :benchmarks:jmh -PjmhArgs="SchemaOutputBenchmark -foe true -wi 3 -i 5 -f 3 -t 1 -prof gc"
